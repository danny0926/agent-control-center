# MVP-A 本機版交付紀錄

日期：2026-09-15。這是公開模板的第一批可運作功能；跨電腦控制與額度派工仍依 [實作計畫](IMPLEMENTATION_PLAN.md)後續交付。

## 已交付

- 持久通知中心：Agent 輪次／目標完成、監工需要決策、項目驗收及驗收失效。事件與通知同交易保存，支援已讀、分頁、SSE 續接、重播去重、安靜時段及訂閱偏好。
- 網頁開啟時的桌面提醒入口：由使用者主動授權；一般摘要、多分頁協調，沒有關頁 Web Push。
- 最末層成果驗收：擁有者逐條核對 acceptance 與必要檢查，綁定版本、證據 hash、規則及期限。標為 `owner_attested`，不宣稱系統代跑測試；來源變更會撤銷有效狀態並留下通知。
- 安全預設：runtime 操作預設拒絕；伺服器驗證登入、action 與 browser origin，記錄稽核。移除啟動時略過原生權限的預設旗標；未實作的 fleet 模式拒絕啟用。
- 精確目標：goal epoch、parent/child 身分、要求／啟動／實際模型與停止事件各自保存。歷史通知及指派不因 pane 重用而接到另一個 runtime。
- 公開安裝準備：editable Python 安裝、範例設定、部署／安全／API 契約文件、無部署權限的 GitHub-hosted CI 與隔離瀏覽器測試。

## 已跑驗證

- API：218 項通過、1 項略過。真實 symlink 測試因 Windows 權限略過，另有不需要該 OS 權限的拒絕分支測試通過。
- 前端：19 項測試通過；production build 通過。
- 隔離 Playwright：3 項通過，涵蓋通知持久／去重／已讀、預設拒絕 runtime 操作、390px 手機版面，以及 UI 提交驗收至真 API、成果狀態與通知的完整流程。所有資料與 runtime 均明示為合成。
- 既有資料庫副本 migration：完整性檢查通過，原專案、監工與事件紀錄保留；副本已移除。另於本機服務啟動前在未追蹤的資料目錄保存備份。
- 本機服務：網站與 API 可讀；既有帳密有效，未登入請求拒絕，runtime allowlist 為空。未變更原帳密或操作 cloudflared。
- 公開候選：目前檔案與 Git index 定向掃描未發現既有 `.env` 秘密值；文件另做常見憑證格式與實際隧道網址檢查。這不是完整安全認證。

## 公開版隱私清理

公開版將私人實機測試與原始文件備份留在未追蹤目錄，文件改用合成專案與通用驗收案例，UI 路徑範例及測試識別碼去識別化。MIT 著作權標示與本 repository 的 Git 作者使用專案通用名稱；不沿用機器上的個人全域 Git 身分。密碼、部署資料、備份、截圖與 runtime 輸出不納入公開版本。

## 未跑／尚未支援

- 真實 OS 通知顯示、手機背景推播、關頁通知與公開 tunnel 端到端驗收。
- 真實 Agent 啟動、傳訊或 shell 執行；未使用工作中的 Agent 當測試 fixture。
- 多使用者／多機器 ACL、OS sandbox、節點斷線與停止實驗、真實 AI 額度核算及自動派工。
- GitHub-hosted CI 尚未在遠端執行；目前驗證環境為 Windows。

## 發布與部署決策

LICENSE 已決定採 MIT；公開 repository owner 尚待擁有者決定，因此未建立 remote 或 push。建議公開產品原始碼與私有部署設定分開，秘密只放各安裝的未追蹤設定或 secret store。

第一階段已決定只使用擁有者自己的 Windows 電腦，沿用單機模式與既有登入設定。跨機器 pilot 延後；未來擴充才需要確認節點、中央登入與共享範圍。AI 額度來源仍未指定，不自行存取或搬移帳號憑證。
